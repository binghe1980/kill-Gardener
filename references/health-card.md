# 健康档案(让"进化"可感知)

旧版刻意不给分、只给"验证集 40 场赢 23 平 8"。这在认识论上诚实,但把"用户感到自己的 skill 变强了"这件事完全牺牲掉了——正是"用起来没有进化感"的根源。

健康档案在**不撒谎、不发明假分数**的前提下,把进步变得可感知:它记录每个 skill 的**轨迹**(present→resolved 的失败模式、版本、每轮改了什么为什么更好),让用户看到一条真实的成长曲线,而不是一个凭空的 87/100。

由 `~health [skill]` 触发,也在每轮 `~tune`/`~cultivate` 结束时自动更新。

---

## 健康档案格式(`_runtime/logs/<skill-name>/health.md`)

```markdown
# <skill-name> 健康档案

## 概况
- 类型:功能型 / 审美型 / 创作型 / 混合型
- 当前版本:v3(初始 v1)
- 首次培育:YYYY-MM-DD ｜ 最近培育:YYYY-MM-DD
- 累计轮次:tune ×2,cultivate ×1
- 日志规模:47 条(自动 32 + 回溯 15)

## 失败模式追踪(核心:让进步看得见)
| 失败模式 | 首次发现 | 状态 | 解决于 |
|---|---|---|---|
| 触发词过窄(A2) | v1 | ✅ 已解决 | tune, v2 |
| 缺投稿交付模块 | v1 | ✅ 已解决 | tune, v2 |
| 输出啰嗦膨胀(B2) | v2 | ✅ 已解决 | cultivate, v3(验证集 68% 胜) |
| 审美风格漂移(E1) | v2 | ⏳ 待处理 | 需先建锚点 |
| 长 prompt 下偶发跑偏 | v3 | 🔍 观察中 | 数据不足,继续积累 |

## 版本轨迹
- **v3**(YYYY-MM-DD, cultivate):针对啰嗦膨胀,demonstrate 策略胜出;验证集 40 场赢 27 平 6;啰嗦率从 34% 降到 9%
- **v2**(YYYY-MM-DD, tune):修 3 处结构 bug(引用路径错、触发词过窄)、补投稿交付模块;静态确认,未涉需数据项
- **v1**(YYYY-MM-DD):初始纳入培育

## 沉淀到原则库的经验
- "对声称口语化的 skill,few-shot 比禁用词清单有效"(来自 v3)

## 下一步建议
- 建锚点以处理待办的风格漂移(E1)
- 观察中的长 prompt 跑偏,再积累 ~10 条日志后可深度培育
```

## `~health` 的两种视图

### 单 skill 视图(`~health <skill>`)
展示上面的完整档案。重点是**失败模式追踪表**和**版本轨迹**——用户一眼看到:这个 skill 从 v1 到现在,哪些毛病被治好了、当前还剩什么、下一步往哪走。这就是"进化感"的来源:不是一个数字变大,而是一串真实问题被逐个划掉。

### 全库视图(`~health` 不带参数)
一张总表,横览所有被培育 skill 的健康状态:

```
skill            类型    版本  已解决/待处理  最近培育    下一步
landing-page     审美    v3    5 / 1         3 天前      建锚点处理 E1
short-drama      创作    v2    3 / 2         上周        积累日志
csv-cleaner      功能    v4    6 / 0         2 周前      ✅ 稳定,无待办
...
```

让用户像看"技能树"一样,知道整个 skill 库的健康分布、哪个该管了、哪个已经稳了。

---

## 设计红线(继承旧版的诚实)

1. **绝不产出单一综合质量分**。失败模式的 present→resolved 是真实的、可审计的;"87 分"是凭空的。健康档案用前者。
2. **"已解决"必须有依据**。静态修复(tune)标"静态确认";经验证的(cultivate)附验证集胜率。不把未验证的改动写成"已解决"。
3. **"进步"用具体事实陈述**,不用庆祝语。"啰嗦率从 34% 降到 9%"是进步的证据;"太棒了,大幅提升!"不是。
4. **待处理和观察中的项要如实列出**,不藏问题。健康档案的价值一半在于它诚实地显示"还没搞定什么"。

---

## 为什么这解决了"没有进化感"

用户要的"进化感",不是一个变大的分数(那反而是旧版正确拒绝的东西)。是**看到自己的 skill 在一条可信的轨迹上变好**:v1 有 6 个毛病,现在划掉了 5 个,每一个划掉都有据可查,还剩 1 个、下一步清楚。这种"技能升级"的可视化,既满足了心理上的进步反馈,又没有牺牲这套系统最值钱的诚实。
